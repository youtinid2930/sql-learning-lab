# SQL Learning Lab

A practical repository dedicated to learning, practicing, and mastering SQL Server through hands-on exercises, complex queries, and technical documentation.

## About

This repository documents my journey toward becoming a stronger SQL developer and data professional.

The objective is not simply to learn SQL syntax, but to develop the ability to:

- Understand and solve complex database problems.
- Write clear, efficient, and maintainable SQL queries.
- Work with relational databases and structured data.
- Understand query execution and database performance.
- Analyze data using SQL techniques.
- Explain and document technical solutions.

All exercises are implemented using **Microsoft SQL Server (T-SQL)** unless specified otherwise.

## Topics Covered

The repository progressively explores the following topics:

- SQL fundamentals and data retrieval
- Filtering, sorting, and aggregation
- Joins and set operations
- SQL functions
- Subqueries and Common Table Expressions (CTEs)
- Window functions
- Complex analytical queries
- Views, temporary tables, and stored procedures
- Indexes and query performance
- Query execution plans and optimization
